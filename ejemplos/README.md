# Ejemplos

Artefactos reutilizables y copiables: código y configuración primero, explicación mínima al lado. A diferencia de `docs/` (conceptual) y `casos-de-uso/` (narrativo), acá el foco es "copiá esto y adaptalo".

## Subcarpetas

- [`skills/`](skills/README.md) — `skills` de ejemplo, con su estructura de archivos completa. ✅ Con contenido.
- `claude-md/` — ejemplos de `CLAUDE.md` para distintos tipos de proyecto. 🚧 Pendiente.
- `hooks/` — configuraciones de `hooks` en `settings.json` con casos de uso concretos. 🚧 Pendiente.
- `slash-commands/` — comandos `/` custom listos para copiar. 🚧 Pendiente.
- `mcp/` — configuraciones de servidores MCP. 🚧 Pendiente.

Las carpetas pendientes se crean cuando haya un caso de uso concreto que las justifique, no antes.
