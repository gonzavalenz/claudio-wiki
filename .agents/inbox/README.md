# Inbox de Antigravity CLI

Buzón de handoff entre agentes. Ver la sección "Cómo se pasan trabajo" en [AGENTS.md](../../AGENTS.md).

- Antigravity CLI deja acá sus revisiones/propuestas/borradores como archivos Markdown (`YYYY-MM-DD-tema.md`), en vez de aplicarlos directo sobre `docs/`, `buenas-practicas/`, `casos-de-uso/`, etc.
- Claude Code los procesa y decide qué incorporar a la wiki.
- Un archivo procesado se borra de acá — no se acumulan revisiones ya resueltas.
