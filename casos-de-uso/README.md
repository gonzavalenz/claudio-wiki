# Casos de uso

> 🚧 Borrador — falta completar.

Escenarios reales (o simulados con detalle suficiente para reproducirlos) resueltos con Claude Code, de punta a punta: contexto, problema, cómo se resolvió, qué se aprendió.

Cada caso de uso es un archivo `.md` en esta carpeta (o una subcarpeta si necesita assets propios), con esta estructura sugerida:

```markdown
# Título del caso de uso

**Contexto:** quién, en qué proyecto, con qué objetivo.

**Problema:** qué había que resolver.

**Cómo se resolvió con Claude Code:** pasos, comandos, skills o configuraciones usadas (linkear a `docs/` o `ejemplos/` cuando aplique).

**Resultado / aprendizaje:** qué funcionó, qué no, qué se haría distinto la próxima vez.
```

Todavía no hay casos de uso cargados — se van a ir sumando a medida que aparezcan.
