Empezá acá: la ruta mínima

Si tenés una hora, leé esto en orden y ya trabajás mejor que la mayoría. Después, tené a mano la referencia rápida.

  1. Instalación y primeros pasos

    Instalá con el instalador nativo, entrá a tu repo, corré claude y después /init. Arrancá con una tarea chica. Cap. 03 →

  2. Contexto: la regla que más impacta

    Una tarea por sesión, /clear al cambiar de tarea, /compact con instrucciones y /context para ver qué lo ocupa. Cap. 05 →

  3. Memoria: un CLAUDE.md corto

    Las reglas fijas del proyecto (comandos de test, convenciones, qué no tocar) para no reexplicar nada en cada sesión. Cap. 06 →

  4. Plan mode y checkpoints

    Explorar → planificar → implementar → commitear. Shift+Tab para planificar sin editar; /rewind para volver atrás. Cap. 09 →

  5. Buenas prácticas

    Los mandamientos en una página: regla → por qué → cómo. buenas-practicas/ →
